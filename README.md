## Assignment 1 - First API Endpoint

A simple CRUD Task API built using Express.js.

### Run
node server.js
### API Documentation
http://localhost:3000/docs
### Endpoints"
GET /tasks
GET /tasks/:id
POST /tasks
PUT /tasks/:id
DELETE /tasks/:id
